# Mapa-de-Rutas-Metro-CDMX
Genera un mapa del metro de la ciudad de mexico con la ruta entre 2 puntos e instrucciones a seguir. 

El script descarga el mapa del metro, lo transforma a nodos y aristas y los combina para que sea una red por donde se puede circular. Después de crear la red se puede ingresar el inicio y el final del viaje y da dos resultados: un mapa con la ruta mas corta y una lista con instrucciones sobre los transbordos.
